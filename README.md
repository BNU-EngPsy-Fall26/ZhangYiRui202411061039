# 叫的是你的名字吗？—— 信号检测论（SDT）情景演示

> 最终版（v2.3，2026-10-11）· 前后端均已上线并联调通过

基于《工程心理学》信号检测论的网页实验演示：使用者扮演"赢麻了"，在拥挤人群中判断
喊出的名字是否是自己；若干轮后，前端自动统计混淆矩阵、计算信号检测指标（d′、c、β、A′）
并绘制 ROC 曲线，同时可将成绩上传至在线排行榜。

---

## 1. 快速开始

- **运行**：直接双击 `index.html`（或用任意现代浏览器打开），无构建、无依赖、无需安装；
- **后端**：已部署在线（`https://mngqwdikvlnf.sealoshzh.site`），前端开箱即连；
- **离线可玩**：后端不可达时游戏本体完全不受影响，仅排行榜不可用。

## 2. 功能总览

| 模块 | 说明 |
| --- | --- |
| **登录** | 12 位学号 + 昵称；学号不合法时红字提示；支持游客模式（成绩不入榜） |
| **调试模式** | 学号输入 `<><>BA` 时昵称锁定为"进入调试模式"，主界面出现调试面板，可调整对话框显示时长（50–3000ms，默认 300ms）；本模式成绩不入榜 |
| **游戏** | 25 / 50 / 100 轮可选；每轮 1 秒后人群小人举手喊名，对话框闪现 0.3 秒；画面正中弹出"叫的是你的名字吗？"是/否判断 |
| **四种结局** | 命中（朋友上前交谈）、漏报（朋友拍背 + 头顶右上方半重合💢）、虚报（陌生人 + 问号）、正确拒绝（无事发生） |
| **暂停 / 返回** | 右上暂停/继续；左上返回会先默认暂停并弹确认框，取消后从当前轮继续 |
| **结果页** | 单屏 16:9 无滚动：混淆矩阵（H/M/F/R）+ 指标卡（d′、c、β、A′，含公式与解读）+ 1:1 ROC 曲线（理论曲线、对角线、操作点标注具体 (F, H) 数值）+ 底部排行榜入口 |
| **排行榜** | 后端真实数据：按 d′ 降序、每人仅显示最高局；🥇🥈🥉 前三名与本人行高亮；底部固定本人排名行；游客点击入口会提示先登录 |

## 4. 玩法流程

1. **登录**：输入 12 位学号 + 昵称进入；或点"游客模式进入"（成绩不计入排行榜）。
2. **主界面**：选择轮数（25 / 50 / 100），点击"开始游戏"。
3. **每轮**：
   - 同步当前轮数 → 1 秒后，人群中随机一个小人举起手臂并弹出对话框，仅显示 **0.3 秒**；
   - 对话框内容随机为信号（"赢麻了"）或噪声（"嬴麻了""羸麻了""赢庥了""赢痳了"等），各 50%；
   - 气泡消失后在画面正中回答"叫的是你的名字吗？"——是 / 否；
   - 判定检测类型（命中 / 漏报 / 虚报 / 正确拒绝），切换对应结局场景与提示框。
4. **结果**：混淆矩阵、四大比率、d′ / c / β / A′（含通俗解读）、ROC 曲线；正式账号成绩自动上传。
5. **排行榜**：查看全服排名，底部固定显示自己的名次。

## 5. 统计口径

| 指标 | 公式 | 说明 |
| --- | --- | --- |
| 命中率 H | hits / (hits + misses) | 信号轮中回答"是"的比例 |
| 虚报率 F | fa / (fa + cr) | 噪声轮中回答"是"的比例 |
| 漏报率 M / 正确拒绝率 R | 1 − H / 1 − F | |
| d′ | z(H) − z(F) | 辨别力；计算前对 H、F 做对数线性校正（H±0.5，Macmillan & Kaplan, 1985） |
| c | −[z(H) + z(F)] / 2 | 判断标准，负=宽松、正=严格 |
| β | exp[(z(F)² − z(H)²) / 2] | 似然比，<1 宽松、>1 严格 |
| A′ | 0.5 + (H−F)(1+H−F)/4（H≥F）；0.5 + (H−F)(1+H+F)/4（H<F） | 非参数辨别力 |
| ROC 曲线 | H = Φ(z(F) + d′) | Φ 为标准正态 CDF；图中标出实际操作点 (F=…, H=…) |

> z 反函数采用 Acklam 有理逼近；Φ 采用 W. J. Cody erf 近似。全部计算在浏览器本地完成。

## 6. 后端（FastAPI + MySQL，已上线）

- **地址**：`https://mngqwdikvlnf.sealoshzh.site`
- **接口**：`POST /api/login`（登录/注册）、`POST /api/submit`（上传一局成绩）、`GET /api/leaderboard`（拉取排行榜）
- **数据规则**：排行榜按 d′ 降序；同一玩家多局只保留 d′ 最高的一局；游客与调试模式成绩不上传；学号服务端二次校验（`^\d{12}$`）
- **容错**：上传失败静默忽略（不干扰游戏）；拉取失败在排行榜页提示重试
- **离线/演示**：把 `index.html` 中 `LeaderboardAPI.enabled` 改为 `false`，即回到本地空跑模式（内置 10 个演示玩家 + `localStorage` 成绩，键 `sdt_records_v2`）
- 接口字段契约、建表 SQL、回归测试记录见 **docs/API对接文档.md**
